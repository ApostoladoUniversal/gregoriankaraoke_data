# gregoriankaraoke_data

**Gregorian Karaoke** data: `.ds` DiffSinger inputs, `.json` metadata, `.mid`
MIDI, `.srt`/`.lrc` subtitles/lyrics, `.opus` audio, `.wav` keyboard tones, and
`.py` generator scripts. This repository does **not** contain the engine or the
site.

## Structure

```
data/cc-by-sa-4.0/
  database/
    README.md
    songs.json
    gabc_to_*.py
    <book>/
      <name>/
  keys/
data/cc0-1.0/
  gabc/
    SOURCES.tsv
    <book>/
      <song-id>.gabc
data/odbl-1.0/
LICENSES/
```

Books with 10 or more songs have their own `<book>/` folder; smaller collections are grouped in `other_books/`.

The `gabc/` directory contains the 18,720 source transcriptions used by the
self-contained `gabc_to_*.py` generators in `database/`, organized in the same
`<book>/` folders as `database/` and named `<book>/<song-id>.gabc`. `SOURCES.tsv`
maps each one back to its original GregoBase filename.
